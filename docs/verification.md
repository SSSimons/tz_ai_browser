## Изоляция активного HTML-диалога (23 сентября 2026)

- Поиск Playwright теперь асинхронно определяет открытое видимое `dialog`,
  `role=dialog`, `role=alertdialog` или `aria-modal=true` и ограничивает область
  действия самым вложенным окном. Одинаковая кнопка на затемнённом фоне в поиск не попадает.
- `browser_snapshot` помечает активное окно как `ACTIVE MODAL`, а `browser_inspect_form`
  читает только его поля. Ссылки на поля фона отклоняются, если диалог открылся позже.
- Локальный стенд дополнен одноимённой фоновой кнопкой «Переместить». Полный офлайн-набор
  после изменения: **47 passed**. Реальный Chrome-прогон в этой сессии не выполнен:
  среда отклонила запуск из-за лимита автоматического разрешения команд.

## Повторная проверка и ограниченный живой тест (23 сентября 2026)

- Полный набор: **50 passed in 34.73s**, включая 3 настоящих браузерных прогона
  через Chrome, SeleniumBase CDP, Playwright и stdio MCP. Артефакты:
  `artifacts/full-recheck-20260923`.
- Ruff и проверка форматирования прошли; `pip check` не обнаружил конфликтов зависимостей.
- С разрешения пользователя выполнено ровно **3** запроса `gpt-5.4-mini`, без повторов,
  с `reasoning=none` и пределом 1000 выходных токенов на запрос. Всего: **1459 входных
  и 143 выходных токена (1602 суммарно)**. Все сведения вымышленные, профиль Chrome отдельный.
- Первый запрос: известная зарплата с валютой, периодом и gross не вызвала вопроса.
- Второй запрос выявил ошибку: модель приняла требование поля gross за свойство
  сохранённой суммы. Запуск остановился с ошибкой проверки, без третьего запроса.
  Исходный отчёт: `artifacts/live-review-20260923-154650/result.json`.
- Исправление: требования задачи вынесены отдельно от рабочих сведений в запросе
  проверяющему; инструкция явно запрещает переносить требуемый gross/net на сумму,
  для которой база расчёта не указана.
- Третий запрос проверил только исправленный случай. Модель уточнила gross/net,
  сохранив известные сумму, валюту и период. Отчёт:
  `artifacts/live-review-20260923-154841/result.json`.
- После исправления повторно прошли 47 тестов без браузера. Код браузерных операций
  после полного прогона не менялся. `.env`, основной профиль и база знаний пользователя
  не изменялись; на внешних сайтах действия не выполнялись.

Платная визуальная проверка не запускалась: оставшийся запрос использован для
проверки найденной ошибки. Передача свежего изображения и отклонение результата при
недоступном скриншоте проверены тестами с подменённой моделью и HTTP-транспортом.
Это точечные проверки, а не полный автономный прогон задачи по ТЗ.

`C:/Program Files/Google/Chrome/Application/chrome.exe`.

Модель `gpt-5.4-mini` самостоятельно вызвала MCP `browser_snapshot`, затем

проверяющего использовал сохранённую историю и свежий снимок той же локальной страницы,

- Фактический расход по `usage`: **10 950 входных**, **94 выходных токена**.
- Ограничения: `reasoning=none`, выход до 600 токенов; для последнего запроса - до 300.
- Повторные HTTP-запросы отключены.
- Отчёт: `artifacts/live-smoke-20260921-235043/verified-result.json`.
- Автономные тесты после исправлений: **21 passed**.

Добавлены `AGENT_MAX_API_CALLS`, `AGENT_MAX_OUTPUT_TOKENS` и `AGENT_API_MAX_RETRIES`.
